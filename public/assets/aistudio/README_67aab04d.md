# Hein.Oxide — Personal Branding Website

> *"The channel isn't chasing scale — it's keeping a record of places worth remembering exactly as they felt in Rakhine."*

Official Personal Branding Website for the **HeinOxide** YouTube channel. Designed with **Claude 3.5 Sonnet**, with code review, architecture, and deployment optimization analyzed and managed by **Hein Sitt Htun**.

---

## 📌 Project Overview

This repository contains the source code and media assets for the official personal branding web experience of **HeinOxide**. The platform showcases visual storytelling, cinematic drone footage, and travel documentaries focused on capturing authentic moments and places across Rakhine State.

---

## 🛠️ Tech Stack & Tools

* **Frontend Structure:** HTML5, Modern CSS / Tailwind CSS
* **Interactivity & Animations:** JavaScript, GSAP (GreenSock Animation Platform) & ScrollTrigger
* **Design & AI Assistance:** Claude 3.5 Sonnet
* **Code Analysis & Optimization:** Hein Sitt Htun
* **Version Control & Hosting:** Git, GitHub, GitHub Pages & Vercel

## 🚀 Local Development Setup

To run this project locally on your machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/heinsitt/Hein.Oxide-Project.git
   ```

2. **Navigate to project directory:**
   ```bash
   cd Hein.Oxide-Project
   ```

3. **Open in VS Code or Launch Live Server:**
   ```bash
   code .
   ```
   Open `heino-xide-video.html` (or `index.html`) using VS Code Live Server extension.
